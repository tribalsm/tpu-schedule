# Расписание ТПУ

- [Открыть приложение](https://tribalsm.github.io/tpu-schedule/app/)
- [Открыть оригинал на текущую неделю](https://tribalsm.github.io/tpu-schedule/)
- [Сохранить ссылку на оригинал в закладки](https://tribalsm.github.io/tpu-schedule/?setup)

В приложении можно просматривать занятия по дням и неделям, переключать группу, искать преподавателей, добавлять их в избранное и импортировать расписания в формате iCal. Группа 8К53Т выбрана по умолчанию. Ближайшее и текущее занятие определяются по времени Томска.

## Локальный запуск

Требуется Node.js 24. Выполните в каталоге репозитория:

```bash
cd pwa
npm ci
npm run dev
```

Проверить сборку и офлайн-запуск:

```bash
npm test
npm run build
npm run preview
```

Service Worker включён в production-сборке. GitHub Actions собирает её в каталог `/app/` на GitHub Pages. Корневые файлы обслуживают старую ссылку и режим `?setup`.

## Данные и офлайн-режим

Источник: [ИПК Расписание учебных мероприятий ТПУ](https://ro-rasp.tpu.ru/). Публичный снимок содержит штатные выгрузки за 23 ноября - 27 декабря 2026 года для группы 8К53Т и Сергея Геннадьевича Цапко. Снимок показывает время экспорта. Названия и имена отображаются с той полнотой, с которой они присутствуют в источнике.

На странице выбранной группы или преподавателя в ТПУ откройте «Формат iCal» и скачайте файл. Импорт примет `.ics`, сохранит занятия на устройстве и откроет расписание. Для нового преподавателя или группы можно указать исходную ссылку ТПУ. Это позволит открывать правильную страницу ТПУ при переключении недель. Поиск приложения работает по загруженным календарям и встроенным проверенным ссылкам. [Полный каталог преподавателей](https://ro-rasp.tpu.ru/site/teacher.html) доступен на сайте ТПУ.

React и TypeScript отвечают за интерфейс и календарь. Vite собирает статику, Tailwind CSS и стили приложения задают оформление, Lucide предоставляет иконки, ical.js читает файлы календаря. Service Worker сохраняет оболочку, LocalStorage хранит последний успешно загруженный снимок, импортированные файлы в разобранном виде, избранное, группу и тему. После первого успешного открытия и загрузки данных приложение доступно без сети. Очистка данных браузера удаляет локальные настройки и сохранённые расписания.

На Android установите приложение через меню Chrome. На iPhone откройте «Поделиться» в Safari и выберите «На экран Домой». Манифест задаёт самостоятельное окно там, где это поддерживается. Оригинальный [favicon ТПУ](https://ro-rasp.tpu.ru/favicon.ico) сохранён в репозитории. Apple Touch Icon и иконки манифеста получены из него.

## Как обновить выгрузку

В рабочей копии из каталога `pwa` можно добавить вручную полученный официальный файл командой:

```bash
npm run snapshot -- group:44645 group.ics 2026-11-23 2026-12-27
npm run snapshot -- teacher:61829 teacher.ics 2026-11-23 2026-12-27
```

Даты возьмите из имени экспортированного файла. Проверьте изменённый `public/data/snapshots.json` перед коммитом. GitHub Actions публикует артефакт после тестов.

Автоматическое обновление источника требует разрешения ТПУ. [Страница API](https://ro-rasp.tpu.ru/open-api.html) предусматривает заявку, HTML-страницы не разрешают запросы с GitHub Pages через CORS, а [robots.txt](https://ro-rasp.tpu.ru/robots.txt) запрещает автоматический обход. GitHub Actions выполняет только сборку и публикацию. При выдаче доступа минимальная интеграция состоит из закрытого задания по расписанию или одного серверного обработчика с ключом API на сервере. Он использует разрешённые в заявке идентификаторы, проверяет ответы и публикует нормализованный JSON. Публичный интерфейс получает этот JSON со своего домена, а при ошибке использует сохранённую выгрузку.

## Учебная неделя

Неделя меняется в воскресенье в 00:00 по Томску (`Asia/Tomsk`). Для учебного года 2026/27 подтверждены недели 1-51, с 30 августа 2026 по 21 августа 2027 включительно. В январе путь по-прежнему содержит `/2026/`. За пределами подтверждённого периода ссылки ведут на официальный каталог. При публикации нового учебного графика обновите календарь в `pwa/src/calendar.ts` и в корневом `index.html`.

В расписании преподавателя промежутки показывают время между занятиями. Доступность для консультаций следует уточнять у преподавателя.
