# Расписание ТПУ

[Открыть расписание группы 8К53Т](https://tribalsm.github.io/tpu-schedule/)

[Открыть страницу для добавления в закладки](https://tribalsm.github.io/tpu-schedule/?setup). В этом режиме страница остаётся открытой, а адрес очищается от параметра `setup`. Сохранённая закладка автоматически откроет расписание при следующем запуске.

Неделя меняется в воскресенье в 00:00 по Томску (`Asia/Tomsk`). Для учебного года 2026/27 подтверждены недели 1-51, с 30 августа 2026 по 21 августа 2027 включительно. В январе адрес по-прежнему содержит `/2026/`. За пределами этого периода открывается поиск на официальном портале ТПУ. Для следующего учебного года обновите `academicYear`, `firstSunday` и `lastWeek` в `index.html` после проверки календаря и адреса группы на портале.

Переход запускается встроенным скриптом в заголовке HTML. Файл `schedule.js` обслуживает прежние версии страницы, сохранённые в кэше.

Оригинальный [favicon ТПУ](https://ro-rasp.tpu.ru/favicon.ico) хранится в `favicon.ico`. Файл `apple-touch-icon.png` получен из него масштабированием до 180 × 180 пикселей без сглаживания.
